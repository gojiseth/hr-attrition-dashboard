# HR Employee Attrition Analysis | Excel Dashboard

**Project Goal:** Analyze employee attrition patterns across 1,470 records to identify high-risk departments and provide retention recommendations.

### Dataset Overview
- **Records:** 1,470 employees
- **Attributes:** 35 columns including Department, JobRole, Age, Gender, Attrition
- **Scope:** Department-wise attrition analysis

### Key Insights - Full Dataset
1. **Sales has highest attrition:** 20.63% vs 19.05% for HR vs 13.84% for Research & Development
2. **Company Average:** Overall attrition rate = 16.12%
3. **Department Comparison:** Sales attrition is 1.5x higher than R&D
4. **Risk Ranking:** Sales > HR > R&D in terms of attrition rate
